# upaffe v0.4.0

This release completes the authenticated web interface's alignment with the
upaffe product family while preserving its monitoring-first workflows and
operational detail.

## Changes since v0.3.0

- Personal, appearance, and session actions now live in an accessible account
  menu in the compact top-right header. Light, dark, and system choices remain
  local to the browser, synchronize across tabs, and continue following
  operating-system changes while System is selected.
- The authenticated shell now uses consistent product navigation, project
  context, active states, proportions, and responsive behavior. The project
  switcher, account menu, mobile navigation drawer, and confirmation dialogs
  use focus-managed interaction primitives.
- Dashboard and project overviews have a denser, more restrained hierarchy
  while keeping failures, overdue work, maintenance, delivery trouble, and
  incident evidence explicit in text as well as color.
- Monitor inventories, HTTP and push workflows, email settings, and maintenance
  administration now share the same controls, sections, tables, narrow-screen
  cards, status presentation, and destructive confirmation behavior.
- Projects are now managed through a URL-backed inventory with search, live or
  deleted state, sorting, rename, confirmed deletion, and restoration. Project
  creation has moved to a dedicated `/projects/new` workflow with field errors,
  pending feedback, keyboard cancellation, and unsaved-change protection.
- Visual regression coverage now protects complete authenticated shells rather
  than isolated fragments on macOS and Linux. Automated coverage exercises
  every authenticated route across light and dark appearance and phone,
  tablet, 200% zoom-equivalent, and desktop widths, including keyboard and
  WCAG 2A/AA checks.

The release changes the presentation layer only. Monitoring, incident,
maintenance, email-delivery, API, and CLI behavior remain compatible with
v0.3.0, and there is no database migration.

## Install and upgrade

Use the [production installation and update guide](https://github.com/datavisionzero/upaffe/blob/v0.4.0/docs/operations.md)
and deployment files from this tag. Back up the database before updating.

Pin `ghcr.io/datavisionzero/upaffe:v0.4.0` by the digest recorded in the release
assets. Download the `ua_0.4.0_PLATFORM.zip` archive for a supported Linux or
macOS architecture and verify it with `SHA256SUMS` before use. The [web UI
guide](https://github.com/datavisionzero/upaffe/blob/v0.4.0/docs/ui.md)
documents the resulting conventions and responsive behavior.
