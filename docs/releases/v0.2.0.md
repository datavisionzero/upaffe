# upaffe v0.2.0

This release makes monitors easier to find and understand across projects.

## Changes since v0.1.1

- A cross-project monitor inventory lists HTTP and push monitors in one web
  view. Filter by project, state, or type; search project and monitor names,
  keys, and purpose. Open incidents and failing monitors appear first.
- `ua inventory` exposes the same paged inventory for unattended use, with
  structured JSON output and the same filters and search.
- HTTP and push monitors can now have an optional purpose describing what they
  cover. The web forms and CLI can create and edit it. Dashboard health cards,
  project reports, and monitor details show it alongside current status.
- Existing monitors remain valid with no purpose. The database migration adds
  nullable purpose fields and preserves existing monitoring data.

## Install and upgrade

Use the [production installation and update guide](https://github.com/datavisionzero/upaffe/blob/v0.2.0/docs/operations.md)
and deployment files from this tag. Back up the database before updating. A
v0.1.1 image cannot open a database after this release's migration; follow the
documented backup and restore procedure if recovery is needed.

Pin `ghcr.io/datavisionzero/upaffe:v0.2.0` by the digest recorded in the release
assets. Download the `ua_0.2.0_PLATFORM.zip` archive for a supported Linux or
macOS architecture and verify it with `SHA256SUMS` before use. The [CLI guide](https://github.com/datavisionzero/upaffe/blob/v0.2.0/docs/cli.md)
documents the inventory command and monitor purpose fields.
