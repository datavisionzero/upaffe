# upaffe v0.3.0

This release gives the web application a clearer, more consistent interface
across desktop and mobile screens.

## Changes since v0.2.0

- A persistent workspace sidebar now keeps Dashboard, Projects, Monitors, and
  Settings within reach. Project routes add direct links to their overview,
  HTTP monitors, push monitors, and email settings.
- Narrow screens use the same navigation in a focus-managed drawer, and the
  project selector moves directly between project workspaces.
- Light, dark, and system appearance modes are available from the sidebar and
  persist locally in the browser.
- Dashboard, project, monitor, and email administration screens now share
  compact headers, panels, controls, tables, status badges, loading states,
  empty states, and error presentation.
- Monitor inventory results become labeled cards on narrow screens while
  retaining their status evidence and links. Long purpose and guidance text
  wraps cleanly throughout the interface.
- Checked-in visual regression coverage now exercises representative screens
  on macOS and Linux. Responsive and accessibility checks cover the primary
  authenticated routes, keyboard navigation, drawer focus, readable states,
  and horizontal overflow.

The release changes the presentation layer only. Monitoring, incident,
maintenance, email-delivery, API, and CLI behavior remain compatible with
v0.2.0, and there is no database migration.

## Install and upgrade

Use the [production installation and update guide](https://github.com/datavisionzero/upaffe/blob/v0.3.0/docs/operations.md)
and deployment files from this tag. Back up the database before updating.

Pin `ghcr.io/datavisionzero/upaffe:v0.3.0` by the digest recorded in the release
assets. Download the `ua_0.3.0_PLATFORM.zip` archive for a supported Linux or
macOS architecture and verify it with `SHA256SUMS` before use. The [web UI
guide](https://github.com/datavisionzero/upaffe/blob/v0.3.0/docs/ui.md)
documents the interface conventions and responsive navigation.
